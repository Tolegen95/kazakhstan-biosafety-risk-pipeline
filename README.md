# biosafety-risk-pipeline (prototype)

Reference implementation of the unified spatio-temporal-species data model and
method-independent computational core described in the dissertation and in
`MDPI_AppliedSciences_Kadyrov_biosafety_risk_pipeline.docx`. Built to back the
paper's claims with real, runnable, reproducible results instead of design-only
diagrams. Context and status: see `../README.md` at the project root.

## Status

## Data

Raw registries live in `../dataset/` (outside this repo, not tracked in git —
they are institutional data, not public). To regenerate the unified tables:

```bash
cd etl
python3 normalize.py --raw-dir ../../dataset --out-dir ../data/normalized
```

Outputs `anthrax_normalized.csv`, `rabies_normalized.csv`, `fmd_normalized.csv`,
a combined `focus_unified.csv`, and `QUALITY_REPORT.md` (row counts, missing
coordinates, date parsing notes, duplicate-row counts).

Note: FMD is not one of the four case studies in the current article draft,
but real FMD registry data exists (`Baza FMD_2013.xlsx`, 1965-2013, n=1221) and
matches the multi-disease modeling in Abdrakhmanov et al., ICCSA 2019. Whether
to add it as a fifth case study is an open question for the article, not yet
decided here.
